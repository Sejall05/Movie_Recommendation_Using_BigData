# Presentation Outline (10 slides)

1. **Title** — Movie Recommendation System using Big Data Analytics; team/member details.
2. **Problem** — Large movie catalogs make discovery difficult; ratings can help personalize choices.
3. **Objectives** — Build a layered pipeline, clean real data, recommend movies, evaluate, visualize.
4. **Dataset** — MovieLens source, files, fields, and citation.
5. **Architecture** — CSV → Bronze → Silver → Gold → ALS → Streamlit.
6. **Data processing** — type casting, validation, duplicate removal, joins, aggregates.
7. **Recommendation model** — ALS collaborative filtering; train/test split; RMSE evaluation.
8. **Dashboard** — screenshots of KPIs, popular movies, rating distribution, and user recommendations.
9. **Results and limitations** — enter real counts/RMSE from run logs; discuss cold-start and dataset size.
10. **Conclusion and future work** — summary, ranking metrics, content-based model, scheduling/deployment.
